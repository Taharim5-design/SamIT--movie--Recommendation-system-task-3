# SamIT--movie--Recommendation-system-task-3
Smart Movie Recommendation System using Python and Tkinter that recommends movies based on user-selected genres and displays ratings and descriptions. Developed for the SAM IT Technologies AI Internship Program.
Smart Movie Recommendation System

Overview

The Smart Movie Recommendation System is a Python-based application that suggests movies based on the genre selected by the user. It provides an interactive graphical user interface (GUI) built with Tkinter and displays recommended movies along with their ratings and brief descriptions.

Features

- User-friendly graphical interface
- Genre-based movie recommendations
- Displays movie ratings
- Provides short movie descriptions
- Quick and simple navigation

Technologies Used

- Python
- Tkinter

Supported Genres

- Action
- Comedy
- Drama
- Sci-Fi

How to Run

1. Open the project in VS Code.
2. Run the Python file:
   python recommendation.py
3. Select a genre from the dropdown menu.
4. Click Get Recommendations.
5. View the recommended movies with ratings and descriptions.

Project Objective

This project demonstrates the basic concept of a recommendation system by providing movie suggestions based on user preferences.

Output

The application recommends movies according to the selected genre and displays relevant details such as ratings and descriptions in an easy-to-read format.
